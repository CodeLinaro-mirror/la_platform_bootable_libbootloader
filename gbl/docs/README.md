# GBL Documentations

Documentation for GBL developers and firmware developers adopting GBL.

## Formatting

The GBL team and external contributors should use
[Prettier](https://prettier.io/) to ensure consistent formatting across GBL
documentation. A `.prettierrc.toml` file is provided in the GBL root directory
to ensure consistent configuration and simplify IDE integration.

Example command:

```bash
prettier --write ./bootable/libbootloader/gbl/docs/gbl_efi_os_configuration_protocol.md
```
